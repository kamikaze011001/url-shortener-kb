# URL Shortener

A service that turns a long destination URL into a short, shareable link, redirects
visitors who follow that link, and reports how many people did.

This file is a **glossary and nothing else**. It defines what words mean, never how
anything is built. Implementation lives in `docs/`.

## Language

### The link itself

**Link**:
The record that binds one short code to one destination, owned by one person.
_Avoid_: URL, shortlink, slug, entry

**Short Code**:
The unique string that identifies a Link. Either generated by the system or chosen by
the Owner as an Alias.
_Avoid_: hash, token, key, id, slug

**Alias**:
A Short Code chosen by the Owner rather than generated. An Alias is a Short Code; the
distinction is only who picked it.
_Avoid_: custom slug, vanity URL, custom code

**Destination**:
The URL a visitor is sent to when they follow a Link.
_Avoid_: target, long URL, original URL, source

**Short Link**:
The full public URL a person shares — the Short Domain plus the Short Code.
Distinct from the Link, which is the record; the Short Link is the string.
_Avoid_: short URL, shortened link

**Code Namespace**:
The single global set of strings available as Short Codes. Generated codes and Aliases
compete for the same strings; there is no per-Owner scoping.
_Avoid_: keyspace, code space

**Reserved Word**:
A string permanently excluded from the Code Namespace because the system needs it for
its own purposes.
_Avoid_: blacklist, blocked word

**Collision**:
A generated Short Code that is already taken. Resolved by generating another; never by
handing out a taken code.
_Avoid_: clash, duplicate

### Lifecycle

**Active**:
The only state in which a Link redirects. Every other state is indistinguishable to a
visitor.

**Disabled**:
The Owner has switched the Link off. Reversible; the Short Code stays claimed.
_Avoid_: paused, deactivated, suspended

**Expired**:
The Link has passed its expiry moment. Not reversible by waiting, only by the Owner
moving or clearing the expiry.

**Deleted**:
The Owner has removed the Link. It stops redirecting and disappears from their view,
but its Short Code is never released back into the Code Namespace.
_Avoid_: removed, archived, trashed

### People and traffic

**Owner**:
The registered person who created a Link and is the only one who may change, disable,
delete, or see statistics for it.
_Avoid_: user, account, creator, customer

**Visitor**:
Anyone who follows a Short Link. Anonymous and never authenticated.
_Avoid_: user, client, viewer

**Redirect**:
The single act of answering a Visitor with the Destination of an Active Link.
_Avoid_: forward, resolve, lookup

**Click**:
One recorded Redirect. Clicks are counted approximately and deliberately: they are
analytics, not an audit log and not billing data.
_Avoid_: hit, visit, view, impression

### Safety

**Destination Screening**:
Deciding whether a proposed Destination is allowed to be shortened at all — separate
from checking that it is a syntactically valid URL.
_Avoid_: validation, filtering, moderation

**Private Destination**:
A Destination that resolves to an address inside a network the service can reach but
the public cannot. Always refused, because shortening one turns the service into a
proxy into that network.
_Avoid_: internal URL, local address
